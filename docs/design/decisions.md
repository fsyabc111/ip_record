## 工程决策

| ID | 决策 | 取舍 |
| --- | --- | --- |
| E01 | Swift＋AppKit 生命周期＋SwiftUI 内容；单进程 | 原生小体积，控制窗口和退出；无需 helper |
| E02 | 系统 SQLite3；每次检查更新当前摘要，变化才新增历史 | 保留最近确认事实，又控制行数 |
| E03 | C 读取器串行文件模式；XDB 捆绑应用，按地址和版本缓存 | 避免常驻加载约 46 MiB 全库 |
| E04 | 分族 ipify 纯文本 HTTPS 单供应商，不加入未核实备用 | 语义和流量简单；供应商故障会导致出口未确认 |
| E05 | DNS、网关和代理只展示公开系统配置视图 | 不将可见配置升级成实际流量证明 |
| E06 | 不记录账号、口令、PAC 脚本及 PAC 完整 URL；PAC 仅 origin＋开关 | 不引入密钥管理；同 origin 的脚本／路径变化不单独识别 |
| E07 | 关闭历史／设置继续记录；明确退出才结束进程 | 与菜单栏工具习惯一致 |
| E08 | 暂停跨退出和登录保留；恢复时重新建立观测起点 | 尊重暂停选择；不伪造连续覆盖 |
| E09 | 公网失败不额外密集重试，下一次定时／事件／手动检查恢复 | 省电与少联网优先 |
| E10 | 标准日期时间、完整可复制地址、零值不展示成地址 | 可读且避免误导 |
| E11 | 构建目标限定当前系统；SwiftPM＋本地 `.app` 打包 | 不为尚不存在的分发范围增加工程负担 |
