# 界面与地址展示设计

状态：v1.0设计已封版，用户已采纳布局和默认操作规则。界面语言为简体中文；示意数据仅说明排版，不代表已进行本机网络检查。

## 1. 菜单栏入口

- 产品名 `IP Record`。一个固定宽度的单色模板图标，适应明暗菜单栏；不把 IP 常驻显示成一长段文字。
- 正常记录使用网络图标；暂停使用暂停图标；无法保存记录使用带感叹号图标。只有最终状态变化时替换，不持续动画。
- 公网查询失败不弹通知，不持续闪烁。图标辅助功能名称包含记录／暂停／存储异常状态。
- 单击打开或关闭弹窗；弹窗打开、复制、展开和查看历史都不触发新的公网请求。
- 无全局快捷键、右键专用隐藏功能或双击要求。Esc／点击外部关闭弹窗。

## 2. 当前状态弹窗

使用原生 popover，建议初始宽度 392 pt，最大高度不超过屏幕可用区域；内容超出时滚动，底部操作始终可到达。具体像素在原生验收中微调，不改变完整地址可读／可复制的合同。

```text
IP Record                             记录中

公网 IPv4                          [复制]
113.118.113.77
中国 · 广东省 · 深圳市
电信 · 归属地为估计
最近确认：23:10:05

▸ 公网 IPv6                     已获取

本机 IPv4 · Wi-Fi · en0             [复制]
192.168.1.12
▸ 其他本机地址                     3 个
▸ 网络配置

最近检查：23:10:05
[立即检查]             [查看历史…]
[暂停记录]             [设置…]
────────────────────────────────────
[退出 IP Record]
```

“公网 IPv6”默认折叠，展开显示完整地址、独立归属地／组织、确认时间、来源和复制按钮。“其他本机地址”按接口列出全部记录的地址，不能仅列一个任意 IPv6。展开只对本次弹窗保持；下次打开恢复紧凑布局。

IPv4 未获取但 IPv6 成功时，仍保留 IPv4 优先顺序，但 IPv6 折叠行必须明确写“已获取”，不能把总体状态写成“无公网地址”。

### 2.1 本机地址选择与接口

- 优先展示系统公开主 IPv4 接口的地址；主接口不明时才选可用 Wi-Fi／有线接口，仍不明则选其他有效接口。
- 该顺序仅为摘要优先级，不称为公网探测的实际出接口。
- 多个候选地址按地址二进制值稳定排序；摘要一个，其余全部可展开。
- 连接方式来自系统接口信息，不根据 `en0`、`en1` 字符串猜测。无法确定显示“接口 enX”。虚拟接口显示“虚拟／其他”，不猜 VPN 品牌。
- 默认采集已启用、非回环接口上的可用单播地址；全局 IPv6、私有地址、链路本地地址分别标明作用域。
- 回环、未指定、组播和广播地址不作为本机地址展示；未启用接口不占摘要位置。
- 没有 IPv4 时显示“未获取本机 IPv4”；不能拿网关地址或公网查询结果代替。

### 2.2 IP 文本和复制

| 情况 | 显示与复制规则 |
| --- | --- |
| IPv4 | 标准点分十进制，无补零；地址独占一行、等宽字体 |
| IPv6 | 小写、标准零压缩；完整文本，不用中间省略号隐去地址 |
| 过长 IPv6 | 在 `:` 等分隔位置视觉换行；复制结果不含布局换行和空格 |
| link-local IPv6 | 保留已知 `%接口` scope；不展示成可跨接口通用地址 |
| IPv4-mapped IPv6 | 用于比较／归属查询时识别映射的 IPv4，保留原始表示用于详情；不算两个不同公网出口 |
| 子网信息 | 前缀长度在详情单独展示；“复制地址”不附加 `/24` 等前缀 |
| 单地址复制 | 仅复制完整地址，不复制国家、标签、时间或隐藏换行 |
| 多地址复制 | 明确按钮“复制全部地址”，每行 `接口 地址`，按显示顺序 |
| 复制反馈 | 按钮附近短暂显示“已复制”，不使用系统通知，不额外联网 |

完整地址需支持文本选取。复制控件有键盘焦点和明确辅助功能名称，例如“复制公网 IPv6 地址”。颜色不能是唯一的状态说明。

### 2.3 归属地

- 顺序为“国家 · 省／地区 · 城市”。国家代码可用系统本地化名称；外国省市保留数据库原文，不联网翻译。
- 缺失字段直接省略，详情写“数据库未提供城市”等说明；`0`、空字段、`null` 不原样展示。
- 摘要相邻完全相同的地名可以去重；详情始终保留国家、省、城市字段的独立含义。
- 运营商／组织单列，缺失时不硬编码“未知运营商”。库不提供 ASN，界面不放虚假的 ASN 栏。
- 全部归属缺失显示“归属地未知”；库出错显示“归属数据库不可用”。两者都保留 IP。
- 公网 v4/v6 可以有不同归属，绝不合并成一个“当前位置”。本机私网地址不做地理归属查询。
- 信息入口显示数据库版本和生成时间，并说明归属地是估计，代理可能显示出口所在地。

### 2.4 新鲜度与失败

| 最终状态 | 地址区域 | 时间和动作 |
| --- | --- | --- |
| 首次检查 | “正在检查…” | 不展示假地址；按钮“检查中” |
| 成功 | 正常完整地址 | 每族单独“最近确认” |
| 定时检查进行中 | 保留上次成功地址，附“检查中” | 原确认时间不提前更新 |
| 网络上下文刚变化 | 当前地址区域“正在确认新网络出口” | 旧值折叠为“上次记录 · 先前网络状态” |
| 连续网络抖动 | “网络正在变化，暂未确认出口” | 可见本机配置标明采集时段与失稳，不冒充原子快照 |
| 事件限频等待补查 | “等待确认新网络出口” | 说明将在30秒事件冷却结束后检查，不把旧值当当前；可手动要求检查 |
| 查询失败 | “公网 IPv4 查询失败”／“IPv6 出口未确认” | 有旧值时在“上次记录”区域展示；时间保持旧确认时间 |
| 系统路径不可用 | “网络不可用，暂未检查公网出口” | 本机仍可有地址；旧公网值仅作历史信息 |
| 暂停 | 顶部“已暂停” | 显示“暂停前记录”，禁用立即检查，提供恢复 |
| 存储失败 | 顶部“无法保存记录” | 新读取结果标“尚未保存”，不能继续宣称记录成功 |

跨网络的旧值在详情包含来源接口／上下文和时间。超过一个检查周期加 30 秒尚未成功确认时，附“记录可能已过期”；这不是删除地址或推断地址已变化。

时间使用系统当前时区的 24 小时制。今天可显示 `HH:mm:ss`，非今天显示 `yyyy-MM-dd HH:mm:ss`。悬停／详情给出带 UTC offset 的完整时间。相对年龄只在打开弹窗或状态更新时计算，不运行每秒刷新的计时器。

### 2.5 网络配置展开区

- 网关按 v4/v6、可知接口、来源显示；缺失写“系统未提供”，读取失败写“读取失败”。
- DNS 按服务／作用域分组，保持服务器顺序，列出匹配域和搜索域。页尾注明“系统可见配置，可能不完整”。
- 代理分别显示 HTTP、HTTPS、SOCKS、自动配置 PAC、自动发现 WPAD；明确区分“关闭”“未提供”“读取失败”。
- 代理服务器仅显示主机和端口；PAC 仅显示安全 origin，不含账号、口令、路径、查询串或脚本。
- 提示“配置不等于每次请求的实际路径”；不提供改网关、改 DNS、开关代理等控制功能。

## 3. 历史窗口

一个可复用的独立窗口，建议初始 1040×680 pt、最小 820×480 pt。关闭窗口只关闭视图，记录继续。

```text
IP Record · 历史
[最近 7 天 ▾] [全部类型 ▾] [搜索 IP、地区、接口…] [导出…]

首次观测时间         变化类型       公网 IPv4          归属地           摘要
11-07 23:10:05      公网地址变化   113.118.113.77     广东省·深圳市     …
11-07 22:40:02      DNS配置变化    …                  …                 …
11-07 22:35:00      恢复记录       …                  …                 …

选择记录后：完整 v4/v6、本机地址、网关/DNS/代理、各族最近确认、触发原因、归属版本
```

- 按持久化顺序倒序；系统时钟回拨不打乱实际采集先后。记录包含稳定 ID。
- 默认最近 7 天；可选今天、7 天、30 天、全部、自定义日期。长期保留不等于默认加载全部数据。
- 每页 100 条、按游标加载更多。打开窗口和筛选都是本地操作，不触发公网检查。
- 变化类型包含公网地址、本机地址、连接状态、DNS、网关、代理、查询状态、记录空档；一轮多项变化可同时显示标签。
- 搜索只查询本地已保存的地址、接口、国家省市和组织，包含国家代码及中文国家名称别名；参数绑定，不把搜索内容拼成 SQL。
- 选中详情显示完整历史快照；“上次记录”字段不能冒充当时成功确认的地址。
- 重复成功检查只延长当前状态的最近确认时间；不得产生大量相同历史行。历史不显示“连续使用 X 小时”，只显示首次观测和最近确认。
- 需要比较时显示“与上一条相比”新增／移除地址、DNS／代理变动；比较基于数据，不根据地名变化猜人移动。
- 空态区分从未记录、筛选无结果、历史被清空、存储不可用。无结果不能伪装成加载中。
- 时间按当前时区显示；导出保留 UTC 和观测时区。调整时区只改变展示，不修改历史事件。

## 4. 设置和首次启动

设置只有一个窗口，分为通用、记录与数据、归属数据库、关于四个区块。默认跟随系统明暗外观；不提供无关主题和动画设置。

### 首次打开

首次用户主动启动可显示一次简短说明窗口：菜单栏位置、5 分钟检查、归属离线查询、公网检查需访问 ipify、历史保存在本机。“登录时启动”预先勾选，可取消；点击“开始记录”后启动并尝试注册。

后续登录启动、定时检查和唤醒都不自动弹出窗口。重新双击正在运行的应用只打开当前弹窗，不创建第二个进程或图标。

### 登录启动

UI 读取系统实际状态，不只显示本地偏好。状态为已启用、需系统允许、未启用、不可用／注册失败。用户系统中关闭后不能反复自动注册。
注册失败可在系统中手动将固定安装路径的应用加入“登录时打开”；该模式明确标“由系统设置管理”，不由应用假装能读写其状态，不重复配置两种模式。

### 记录与数据

- 默认 5 分钟；可选 5／15／30 分钟，没有秒级轮询。系统事件检查不受该周期阻止，但有30秒事件限频。
- 暂停跨退出和登录保留；恢复立即检查。暂停中“立即检查”不可用，避免绕过暂停语义。
- 历史长期保留；可查看文件位置和磁盘使用量，按用户动作导出或清空，不暗中自动删历史。
- 导出支持 CSV 摘要和 JSON 完整数据；保存前可选当前筛选或全部历史，显示条数／范围。
- “清空历史…”必须显示确认：保留当前状态、设置和归属库；下次变化开始新增历史。取消无副作用。
- 导出显示进度和取消按钮，一次只允许一个任务；超过两分钟未完成提示缩小日期范围重试，不保存半成品。

### 归属数据库与关于

显示数据来源、每族生成时间、当前版本／校验状态、许可证，以及应用版本和运行环境。用户已选择第一版随应用版本更新数据库，设置不提供在线更新／任意数据库导入按钮。

## 5. 键盘、辅助功能和退出

- 菜单／弹窗可用键盘完成展开、复制、检查、查看历史、暂停和退出；不能只支持鼠标悬停。
- 在历史／设置窗口内 `⌘W` 关闭窗口，`⌘Q` 明确退出应用。菜单始终有“退出 IP Record”。
- 退出取消在途检查并关闭文件；没有 helper 在退出后继续记录。
- “退出”和“暂停”不取消登录启动偏好；暂停偏好会保留，退出后下次登录是否启动由系统设置决定。
- 错误说明在产品界面使用可理解语言，技术码、数据库哈希等放详情，不把 actor、SQL、XDB 指针等实现细节塞进日常流程。
