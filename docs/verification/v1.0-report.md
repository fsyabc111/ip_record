# IP Record v1.0 实现与验证

日期：2026-11-08（Asia/Taipei）。环境：当前 Apple Silicon Mac、macOS 27.0.1（26A434）、Apple Swift 6.4、CLT 27。

## 交付与证据边界

已实现可安装原生应用：单进程菜单栏、AppKit 生命周期、SwiftUI 内容、SQLite 变化历史、官方 C 读取器的全球双栈离线归属、独立分族探测、筛选／详情／复制／导出／清空、暂停持久化及登录项管理。没有云端组件、Python 运行时、后台 helper、定位、抓包或在线归属查询。

不能宣称“38个场景全部实机验收通过”。下表分别标明自动化、模拟、当前网络和实际界面证据。真实睡眠／重新登录、其他物理连接及代理切换留给用户方便时验证。后台 RSS 预算仍有差距，详见资源节。最终安装已通过首次说明开始记录，正式历史已有启动和真实状态记录；窗口已关闭，应用保持后台运行。

- 数据：`~/Library/Application Support/local.fsy.iprecord/`；目录0700，数据库、WAL与SHM按0600限制。
- `scripts/build-app.sh`、`scripts/install-app.sh`、`scripts/verify-bundle.sh`、`scripts/test.sh` 可复现构建、签名、资源及测试检查。

## 资源测量

`python3 scripts/measure-resources.py <已安装二进制> <隔离目录>` 进行30分钟真实网络记录，每10秒读取公开进程资源计数与数据库大小。没有窗口轮询、网络抓包或向外上传配置。

测量包括实际网络事件以及并行原生界面／辅助功能检查，并非完全无干预的稳定网络。最初约10分钟RSS约74–76MiB；之后升高，原因未隔离确认。已优化XDB流式校验的临时对象生命周期，并释放关闭窗口和popover的SwiftUI内容；仍不能把80MiB后台目标标成通过。

测量实际1811.32秒、181个采样点，最后进程样本在1801.314秒，退出码0，session clean_exit=1。数值见 [resources-summary.json](resources-summary.json)：

| 指标 | 实测 |
| --- | ---: |
| 全程单核CPU均值 | 0.0908% |
| 最后10分钟单核CPU均值 | 0.0156% |
| 60秒后RSS范围 | 73.75–136.53 MiB |
| RSS峰值 | 136.53 MiB（高于80MiB目标） |
| 最后physical footprint | 48.80 MiB（不替代RSS） |

采样二进制的SHA-256保存在摘要中。采样与后续界面／校验／权限修复并行，这不是最终源码HEAD重新运行的30分钟结果；最终构建另做34项测试、签名／资源验证和程序级暂停重启回归。不得把早期74–76MiB短样本、最后CPU均值或footprint单独用来宣称最终资源门通过。

`ri_user_time`／`ri_system_time`按Mach timebase换算，不能直接当纳秒；当前机器为41.6667ns/tick。RSS与physical footprint分别报告，不用后者替代RSS预算。请求数是应用启动的分族尝试（含后续取消），不是抓包统计。

## 用户方便时的验收

不需要为开发专门重启、登出或修改日常网络。以下可在日常自然发生时完成：

1. **睡眠**：保持“记录中”，记下最近确认，正常睡眠超过一个周期；唤醒后打开历史，应有sleep/wake标记、新观测起点、不补多轮tick。再暂停后重复，唤醒应仍暂停且立即检查不可用。
2. **重新登录**：先在设置确认系统登录项状态；下次自然重新登录时检查菜单栏图标及无说明弹窗。暂停后退出、下次登录应仍暂停。可在系统撤销登录项后手动打开，应用应显示未启用且不自动重新注册。
3. **自然切换网络／代理**：只在本来需要切换时观察历史。本机配置来源可见，旧出口降为上次记录；一族失败不覆盖另一族，IPv6失败不等于电脑没有IPv6。不要为了验收修改当前DNS或代理。
4. **键盘／辅助功能／规模界面**：核对⌘Q、所有展开和IPv6完整复制、VoiceOver名称；在隔离合成历史中验证十万条完整界面首屏／长滚动。正式历史不导入合成记录。

## 已知限制

- 后台80MiB RSS目标尚未完整达成；界面150MiB、完整菜单200ms和十万条UI500ms预算未全面测量。
- 只覆盖当前Mac与当前网络，不推导IPv6成功、所有VPN／代理组合或全部DNS解析视图。
- v1只提供初始schema；未知／较新库拒绝覆盖，未来迁移必须先用已实现的SQLite backup能力生成备份。
- 导出和取消在每行／批次检查；120秒目标不等同于已证明任意文件系统阻塞调用都能在精确墙钟内中止。
- 本机ad hoc签名通过不等于对外分发、公证或其他Mac兼容承诺。
